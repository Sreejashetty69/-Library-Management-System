# 📚 Library Management System

A colorful and user-friendly Library Management System built using Python and Colorama. This application allows users to efficiently manage books through an interactive command-line interface.

## 🌟 Features

* Add New Books
* View Available Books
* Search Books
* Issue Books
* Return Books
* Library Statistics Dashboard
* File Handling for Data Persistence
* Colorful CLI using Colorama
* Automatic Sample Book Initialization

## 🛠️ Technologies Used

* Python 3
* Colorama
* File Handling
* CLI (Command Line Interface)

## 📊 Available Operations

### ➕ Add Book

Add new books to the library collection.

### 📖 View Books

Display all available books.

### 🔍 Search Book

Search books using book titles.

### 📤 Issue Book

Issue books and update library records.

### 📥 Return Book

Return issued books back to the library.

### 📈 Statistics

View:

* Total Books
* Available Books
* Issued Books
